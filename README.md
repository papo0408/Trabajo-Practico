# Trabajo Práctico

Página web de productos estáticos.

## Cómo ejecutar en el navegador

1. Abre el archivo `Pagina/productos.html` directamente desde el explorador de archivos.
2. O ejecuta un servidor local desde la carpeta `Pagina`:

```powershell
cd Pagina
py -m http.server 8000
```

3. Abre en tu navegador:

```
http://localhost:8000/productos.html
```

## Uso

- Navega por los productos.
- Agrega productos al carrito.
- Realiza la compra de prueba.
- Envía el formulario de contacto.
